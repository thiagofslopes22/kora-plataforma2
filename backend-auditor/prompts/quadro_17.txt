## REGRAS CRÍTICAS:

1. Usar sempre contas sintéticas (código pai) — nunca subcontas com sufixo .0.1, .0.2, .0.3, .0.4
2. As contas sintéticas já agregam principal + multas + dívida ativa — não somar separadamente
3. IRRF = código 1113.03.0.0.00.00 (agrega trabalho + outros rendimentos)
4. ISS = código 1114.51.0.0.00.00 (não usar 1114.51.1.0)
5. FPM = somente cota mensal 1711.51.1.0.00.00 — excluir cotas extraordinárias 1711.51.2.0
6. ITR = 0.00 nos impostos; extrair como transferência em 1711.52.0.0
7. Coluna: sempre ARRECADADA — nunca a coluna ORÇADA
8. Não encontrado = 0.00
9. Valores: decimal 2 casas

---

## CÁLCULOS:

javascript // Receita de impostos total_impostos = iptu + itbi + iss + irrf // (multas, dívida ativa e encargos = 0.00 pois já incluídos nas sintéticas)  // Transferências constitucionais total_transferencias = fpm_mensal + itr + ipva + icms                      + icms_desoneracao + ipi + iof_ouro  // Base de cálculo base_calculo = total_impostos + total_transferencias  // Mínimo saúde aplicacao_minima = base_calculo * 0.15  // FPM extraordinário (informativo — excluído da base) impacto_fpm_extra = fpm_extraordinario * 0.15

javascript ✓ iptu   = código 1112.50.0.0 ARRECADADA ✓ itbi   = código 1112.53.0.0 ARRECADADA ✓ iss    = código 1114.51.0.0 ARRECADADA ✓ irrf   = código 1113.03.0.0 ARRECADADA ✓ fpm    = código 1711.51.1.0 ARRECADADA (NÃO usar 1711.51.2.0) ✓ itr    = código 1711.52.0.0 ARRECADADA ✓ ipva   = código 1721.51.0.0 ARRECADADA ✓ icms   = código 1721.50.0.0 ARRECADADA ✓ ipi    = código 1721.52.0.0 ARRECADADA ✓ total_impostos > 0 ✓ total_transferencias > 0 ✓ base_calculo = total_impostos + total_transferencias ✓ aplicacao_minima = base_calculo * 0.15 ✓ fpm_extraordinario registrado mas NÃO somado na base

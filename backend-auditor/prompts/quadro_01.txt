## FORMATO DO ARQUIVO

O arquivo já está organizado em três colunas limpas:

```
CÓDIGO                 DESCRIÇÃO                    ARRECADADA
1112.50.0.0.00.00      IPTU                         XXX.XXX,XX
1112.53.0.0.00.00      ITBI                         XXX.XXX,XX
```

**Instrução:** localizar o código, ler o valor da coluna ARRECADADA diretamente. Sem inferência, sem regras de colunas múltiplas. O valor que está na terceira coluna é o valor correto.

Se a linha do código não existir no arquivo: usar **0.00**.

## REGRAS:

1. Usar sempre contas **sintéticas** (código pai) — ex: `1112.50.0.0` e não `1112.50.0.1`
2. IRRF = código `1113.03.0.0` — NÃO usar `1113.00.0.0` (inclui IRPJ)
3. Ler o valor **diretamente** da coluna ARRECADADA — não inferir nada
4. Código não encontrado = **0.00**
5. Dedução FUNDEB = **0.00** (aplicar: false) para o legislativo
6. Percentual fixo = **7%**
7. Valores: decimal 2 casas

---

## CÁLCULOS:

```javascript
receita_tributaria.subtotal = iptu + itbi + irrf + iss
                            + taxas_poder_policia
                            + taxas_prestacao_servicos
                            + contribuicoes_melhorias
                            + divida_ativa_tributaria
                            + multas_juros_tributos
                            + cosip

transferencias_estado.subtotal = icms + ipva + ipi + cide + icms_desoneracao

transferencias_uniao.fpm_total = fpm_cota_mensal + fpm_cotas_extraordinarias
transferencias_uniao.subtotal  = fpm_total + itr

base_calculo  = receita_tributaria.subtotal
              + transferencias_estado.subtotal
              + transferencias_uniao.subtotal

limite_anual  = base_calculo * 0.07
limite_mensal = limite_anual / 12
```

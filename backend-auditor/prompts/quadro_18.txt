## REGRA CRÍTICA DE LEITURA DO ANEXO 10

### Estrutura da linha:
ORÇADA | ARRECADADA | DIFERENÇA | CÓDIGO | DESCRIÇÃO

### ⚠️ REGRA DE IDENTIFICAÇÃO DA COLUNA ARRECADADA:

O Anexo 10 apresenta os valores em colunas nem sempre separadas por delimitadores claros. Aplicar a seguinte lógica para identificar o valor ARRECADADO:

javascript // Cada linha tem formato: V1 V2 V3 CÓDIGO DESCRIÇÃO // onde: // V1 = ORÇADA // V2 = ARRECADADA (pode estar vazia/ausente) // V3 = DIFERENÇA (PARA MAIS ou PARA MENOS)  // REGRA 1 - Três valores distintos presentes: // Ex: "888.065,64  957.136,88  69.071,24  1112.50.0.1" // → ORÇADA=888.065,64 | ARRECADADA=957.136,88 | DIF=69.071,24 ✓  // REGRA 2 - Apenas dois valores iguais (sem arrecadada): // Ex: "562.005,00  562.005,00  1723.50.0.1" // → ORÇADA=562.005,00 | ARRECADADA=0,00 | DIF=562.005,00 // ⚠️ Quando V1 == V2 e não há V3, significa que ARRECADADA está vazia // O valor que parece "repetido" é ORÇADA e DIFERENÇA PARA MENOS  // REGRA 3 - Apenas um valor presente: // → ARRECADADA = 0,00 

### Exemplos práticos:
| Linha no PDF | ORÇADA | ARRECADADA | Interpretação |
|---|---|---|---|
| 888.065,64 957.136,88 69.071,24 1112.50.0.1 | 888.065,64 | 957.136,88 | 3 valores distintos → arrecadou |
| 562.005,00 562.005,00 1723.50.0.1 | 562.005,00 | 0,00 | 2 valores iguais → não arrecadou |
| 162.900,00 162.900,00 1114.51.1.2 | 162.900,00 | 0,00 | 2 valores iguais → não arrecadou |
| 15.239.760,89 18.477.926,55 3.238.165,66 1721.50.0.1 | 15.239.760,89 | 18.477.926,55 | 3 valores distintos → arrecadou |

## REGRAS GERAIS:

1. Usar contas sintéticas (código pai) — nunca subcontas .0.1, .0.2 etc.
2. Contas sintéticas já agregam principal + multas + dívida ativa
3. FPM = somente cota mensal 1711.51.1.0 — excluir cotas extraordinárias 1711.51.2.0
4. ITR = 0.00 nos impostos; extrair como transferência em 1711.52.0.0
5. Não encontrado ou ARRECADADA vazia = 0.00
6. Valores: decimal 2 casas

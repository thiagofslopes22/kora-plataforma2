javascript if (saldo_final > 0) {   situacao = "Suficiente" } else if (saldo_final < 0) {   situacao = "Insuficiente" } else {   situacao = "Equilibrado" }

## REGRAS:

1. Valores: decimal 2 casas
2. (C) = somente "OUTRAS OBRIGAÇÕES A CURTO PRAZO" — nunca incluir fornecedores, pessoal ou demais grupos
3. Priorizar Anexo 14 para caixa bruto (A), depósitos (B) e outras obrigações (C)
4. Priorizar Anexo 12 para todos os restos a pagar (E, F, G, I, J)
5. Se não encontrado: usar 0.00
6. Item: texto exato conforme especificado
7. Situação: primeira letra maiúscula

---

## MAPEAMENTO SIMPLIFICADO:

ANEXO 14:   Ativo Circulante → Caixa e Equivalentes                  = (A)   Passivo Circulante → Valores Restituíveis                 = (B)   Passivo Circulante → Outras Obrigações a Curto Prazo      = (C)  ← SOMENTE ESTA LINHA  ANEXO 12:   RP Processados   → col. (a) anteriores + col. (b) inscritos  = parte de (E) + (F)   RP Não Processados → col. (a) anteriores + col. (b) inscritos = parte de (E) + (G)   RP Processados   → col. pagos + cancelados                   = parte de (I) + (J)   RP Não Processados → col. pagos + cancelados                 = parte de (I) + (J)   RP → coluna SALDO (ambas tabelas somadas)                    = (L)  CÁLCULOS:   (D) = (A) - (B) - (C)   (H) = (E) + (F) + (G)   (L) = (H) - (I) - (J) - (K)   (M) = (D) - (L)

## CÁLCULOS:
javascript // Variação Absoluta variacao_absoluta = patrimonio_liquido_atual - patrimonio_liquido_anterior  // Variação Percentual if (patrimonio_liquido_anterior != 0) {   variacao_percentual = ((patrimonio_liquido_atual - patrimonio_liquido_anterior) / Math.abs(patrimonio_liquido_anterior)) * 100 } else {   variacao_percentual = 0 }  // Arredondar para 2 casas decimais variacao_percentual = Math.round(variacao_percentual * 100) / 100 

## VALIDAÇÕES:
javascript ✓ patrimonio_liquido_anterior existe (pode ser negativo) ✓ patrimonio_liquido_atual existe (pode ser negativo) ✓ variacao_absoluta = atual - anterior ✓ variacao_percentual calculado corretamente ✓ valores com 2 casas decimais 

## REGRAS:

1. Valores: decimal 2 casas
2. Aceitar valores negativos (passivo a descoberto)
3. Percentual: usar valor absoluto do anterior no denominador
4. Se anterior = 0: percentual = 0
5. Fonte: Quadro Principal (não Quadro B)
